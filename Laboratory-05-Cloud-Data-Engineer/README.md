
# Laboratory 05 – Cloud Data Engineer

## Mission Overview

In this laboratory activity, I worked as a Cloud Data Engineer at CloudNova Technologies. The main goal of this mission was to understand cloud storage and deploy an S3-compatible object storage server using MinIO and Docker.

I learned how object storage can be used to store large amounts of unstructured data such as images, videos, and backups. I also deployed MinIO, accessed its web console, created a storage bucket, and uploaded a sample file.

## Objectives

- Differentiate between Block, File, and Object Storage.
- Deploy an S3-compatible Object Storage server using MinIO and Docker.
- Access a cloud service via a web interface using port forwarding.
- Create a storage bucket and upload objects.
- Document cloud storage operations using Markdown.
- Continue expanding my GitHub Cloud Computing Portfolio.
