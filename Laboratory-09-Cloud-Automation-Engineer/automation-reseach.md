# Automation Research

## 1. Bash Script

A Bash script is a file that contains commands that Linux can execute in order. The `#!/bin/bash` line, also called the shebang, tells the system to use Bash to run the commands in the file. Bash scripts help automate repetitive tasks, such as creating backups and managing files.

## 2. Variables

Variables store information that a script can use, such as folder paths and timestamps. For example, `$BACKUP_DIR` stores the path of a backup folder, making the script easier to update without changing the same path in several places.

## 3. Cron Job

A cron job is a scheduled task in Linux that runs commands or scripts automatically at a specific time or interval. It is useful in cloud operations because it can perform repeated tasks, such as backups, without requiring someone to run them manually every time.

## Conclusion

Bash scripts, variables, and Cron jobs are useful tools for cloud automation. They help make routine tasks faster, more consistent, and easier to manage. Learning these tools is important for maintaining and automating Linux systems.
