# Reflection

In this laboratory, I learned how to automate backup tasks using Bash scripting and Cron jobs. I learned how to create a script, set file permissions using `chmod`, and compress application data into a `.tar.gz` file. I also learned how to schedule backups to run automatically every day at 2:00 AM using Cron.

This activity helped me understand how automation makes cloud operations easier, faster, and more organized. I realized that automated backups are important because they help protect data and reduce the need for manual work. Overall, this laboratory improved my basic Linux scripting and cloud automation skills.
