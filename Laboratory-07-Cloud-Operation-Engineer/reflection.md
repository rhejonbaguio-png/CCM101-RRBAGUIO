## Reflection

In this laboratory activity, I learned how to monitor a Linux server and observe the performance of a Docker container. I used commands such as `free -h`, `df -h /`, and `top` to check system resources. I also deployed an Nginx web server using Docker and tested its accessibility using the `curl` command.

One important thing I learned was how to identify a 404 Not Found error by checking application logs. I also learned how `docker stats` helps monitor CPU and memory usage in real time. This activity helped me understand the importance of monitoring and troubleshooting to maintain a reliable web application.

Overall, this laboratory improved my knowledge of Linux commands, Docker container monitoring, and application log analysis. These skills are useful for managing and maintaining cloud-based applications.
