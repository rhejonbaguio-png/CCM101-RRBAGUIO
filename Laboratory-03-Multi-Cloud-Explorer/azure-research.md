# Microsoft Azure Research

## Brief Overview

Microsoft Azure is a cloud computing platform developed by Microsoft. It provides a wide range of cloud services for computing, storage, networking, databases, security, analytics, artificial intelligence, and application development. Azure allows individuals, businesses, and organizations to create, deploy, manage, and scale applications and IT resources through the internet.

Azure supports both new cloud-based applications and the migration of existing systems from traditional physical servers to cloud infrastructure. It also follows a flexible, pay-as-you-go pricing model, allowing organizations to use and pay for resources based on their requirements.

## Global Infrastructure

Microsoft Azure operates a large global cloud infrastructure distributed across different geographical locations around the world. Its infrastructure is organized into **Regions**, which are geographical areas containing Azure datacenters. Many Azure regions also support **Availability Zones**, which are physically separate locations within a region designed to improve application availability and fault tolerance.

Azure's global infrastructure allows organizations to deploy applications closer to their customers. This can help reduce network latency, improve performance, and provide greater reliability. Organizations can also select different regions based on data residency, compliance, performance, and business requirements.

## Cloud Management Console

The **Microsoft Azure Portal** is a web-based management console used to create, configure, manage, monitor, and delete Azure resources. It provides a graphical interface that allows users to manage cloud services without relying entirely on command-line tools.

Through the Azure Portal, users can manage virtual machines, storage accounts, virtual networks, databases, security settings, user identities, subscriptions, resource groups, monitoring tools, and billing information. Azure also provides additional management tools such as Azure CLI and Azure PowerShell for users who prefer automation and command-line administration.

## Four (4) Core Services

| Azure Service | Category | Description |
|---|---|---|
| **Azure Virtual Machines** | Compute | Provides virtual computers that can run Windows or Linux operating systems and applications in the cloud. |
| **Azure Blob Storage** | Storage | Provides scalable object storage for unstructured data such as documents, images, videos, backups, and other files. |
| **Azure Virtual Network** | Networking | Allows organizations to create private networks and securely connect Azure resources and applications. |
| **Microsoft Entra ID** | Identity & Security | Provides identity and access management for users, applications, devices, and organizational resources. |

## Three (3) Advantages

1. **Microsoft Integration** – Azure integrates well with Microsoft technologies such as Windows Server, Microsoft 365, SQL Server, and other Microsoft business solutions.

2. **Scalability and Flexibility** – Organizations can increase or decrease computing, storage, and networking resources based on changing workloads and business requirements.

3. **Global Infrastructure** – Azure provides cloud infrastructure in many geographical regions, allowing organizations to deploy applications closer to their users and improve availability and performance.

## Typical Enterprise Use Cases

Microsoft Azure can be used by enterprises for:

- Hosting websites and enterprise applications
- Running Windows and Linux virtual machines
- Storing business files, documents, images, and backups
- Creating and managing cloud-based databases
- Developing and testing applications
- Data analytics and business intelligence
- Artificial intelligence and machine learning
- Backup and disaster recovery
- Hybrid cloud environments
- Migrating existing company systems to the cloud
- Supporting remote and distributed applications
- Managing user identities and access permissions
- Building scalable enterprise systems

## Security and Management

Azure provides various security and management features that help organizations protect their cloud resources. Microsoft Entra ID can be used to manage identities and access permissions, while Azure security and monitoring services help organizations identify potential threats, monitor resources, and maintain compliance.

Organizations can also use role-based access control (RBAC) to control what users are allowed to do within their Azure environment. This helps administrators apply the principle of least privilege and reduce unauthorized access to cloud resources.

## Azure in Cloud Computing

Microsoft Azure is an important cloud computing platform because it provides infrastructure, platforms, and services that organizations can use without having to maintain all physical hardware themselves. Businesses can use Azure to quickly deploy applications, store data, scale resources, and manage IT infrastructure through cloud-based services.

Azure is especially useful for organizations that already use Microsoft technologies because it provides strong integration with Microsoft's existing products and enterprise solutions.
