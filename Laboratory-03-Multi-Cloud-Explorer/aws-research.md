# Amazon Web Services (AWS) Research

## Brief Overview

Amazon Web Services (AWS) is a cloud computing platform provided by Amazon. It offers a wide range of cloud services that allow individuals, developers, and organizations to run applications, store data, manage databases, create networks, and use computing resources through the internet. AWS follows a pay-as-you-go model, allowing organizations to use resources depending on their needs.

## Global Infrastructure

AWS operates a large global infrastructure that is comprised of Regions and Availability Zones. A Region is a geographical area where AWS has infrastructure, while Availability Zones are separate locations within a Region that contain data centers. This structure allows organizations to deploy their systems closer to users and improve availability, performance, and reliability.

## Cloud Management Console

The AWS Management Console is a web-based interface used to access and manage AWS cloud resources. It provides centralized access to AWS services and allows users to create resources, configure services, monitor applications, manage security, and check account and billing information.

## Four (4) Core Services

| AWS Service | Category | Description |
|---|---|---|
| Amazon EC2 | Compute | Provides virtual servers that can be used to run applications and workloads in the cloud. |
| Amazon S3 | Storage | Provides scalable object storage for files, backups, images, videos, and other data. |
| Amazon VPC | Networking | Allows users to create and configure private virtual networks for their AWS resources. |
| AWS IAM | Security | Controls users, roles, permissions, and access to AWS services and resources. |

## Three (3) Advantages

1. **Scalability** – AWS resources can be increased or decreased depending on the needs of an application or organization.
2. **Global Availability** – AWS has infrastructure in different geographical locations, allowing businesses to deploy applications closer to their users.
3. **Wide Range of Services** – AWS provides services for computing, storage, networking, databases, security, analytics, artificial intelligence, and many other areas.

## Typical Enterprise Use Cases

AWS can be used by enterprises for:

- Hosting websites and business applications
- Storing and backing up company data
- Running virtual servers and enterprise systems
- Creating disaster recovery and backup solutions
- Developing and testing applications
- Data analytics and machine learning
- Migrating existing systems from physical data centers to the cloud
