Continue Your Linux Investigation
Linux commands were used in the KillerCoda Playground to examine the basic system information of the server. The investigation included the operating system, CPU information, memory, and available disk space.

Linux Commands Used
The following Linux commands were used to collect the system information:

cat /etc/os-release – displays information about the Linux operating system.
lscpu – displays details about the CPU and its architecture.
free -h – shows the total, used, and available system memory in a readable format.
df -h – displays the used and available disk space.
