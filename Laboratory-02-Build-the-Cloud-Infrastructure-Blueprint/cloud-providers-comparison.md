# Cloud Provider Comparison

## Checkpoint 4 – Research the Major Cloud Providers

This document compares the major infrastructure
services of Amazon Web Services (AWS), Microsoft
Azure, and Google Cloud Platform (GCP). The
comparison focuses on compute, storage, networking,
and identity and access management.



## Cloud Service Comparison

| Infrastructure Component | AWS | Microsoft Azure | Google Cloud Platform |

| **Compute** | Amazon EC2 | Azure Virtual Machines | Compute Engine |
| **Storage** | Amazon S3 | Azure Blob Storage | Cloud Storage |
| **Networking** | Amazon VPC | Azure Virtual Network | Virtual Private Cloud (VPC) |
| **Identity and Access Management (IAM)** | AWS IAM | Microsoft Entra ID | Cloud IAM |



## 1. Compute Resources

**AWS – Amazon EC2**

Amazon EC2 provides virtual servers that can be
used to run applications and services. Users can
select the amount of computing power they need and
change it when necessary.

**Microsoft Azure – Azure Virtual Machines**

Azure Virtual Machines provide virtual computers
that can run applications and different operating
systems. They can be configured based on the
requirements of an organization.

**Google Cloud – Compute Engine**

Compute Engine provides virtual machines that run
applications and workloads on Google Cloud. Users
can select different machine configurations based
on their computing needs.



## 2. Storage Resources

**AWS – Amazon S3**

Amazon S3 is an object storage service used for
storing files and other types of data. It can be
used for backups, websites, applications, and
data storage.

**Microsoft Azure – Azure Blob Storage**

Azure Blob Storage is used to store large amounts
of unstructured data. It can store files such as
images, videos, documents, and backups.

**Google Cloud – Cloud Storage**

Google Cloud Storage is an object storage service
used to store and access data. Data is organized
into storage buckets for easier management.



## 3. Networking Resources

**AWS – Amazon VPC**

Amazon VPC allows users to create a private
network for their AWS resources. It provides
networking features such as subnets, IP addresses,
and routing.

**Microsoft Azure – Azure Virtual Network**

Azure Virtual Network allows Azure resources to
communicate with each other and with external
networks. It provides a secure network environment
for cloud resources.

**Google Cloud – VPC**

Google Cloud VPC provides networking for resources
running on Google Cloud. It allows users to create
networks, subnets, and control network traffic.



## 4. Identity and Access Management

**AWS – AWS IAM**

AWS IAM allows administrators to control access
to AWS resources. It can be used to manage users,
roles, and permissions.

**Microsoft Azure – Microsoft Entra ID**

Microsoft Entra ID is used to manage identities
and access to Microsoft cloud resources. It helps
organizations authenticate users and control their
access.

**Google Cloud – Cloud IAM**

Google Cloud IAM allows administrators to control
who can access Google Cloud resources. Permissions
can be assigned using different roles.



# Guide Questions

## 1. Which cloud provider offers the broadest range of services? Explain your answer.

AWS offers one of the broadest ranges of cloud
services. It provides many services for computing,
storage, databases, networking, security, analytics,
AI, and other cloud technologies.



## 2. Which cloud platform would you recommend for an organization that primarily uses Microsoft products? Why?

I would recommend Microsoft Azure because it works
well with Microsoft products and technologies.
Organizations that already use Windows Server,
Microsoft 365, and other Microsoft services can
easily connect them with Azure.



## 3. Which platform is widely recognized for Artificial Intelligence (AI), Machine Learning (ML), and Kubernetes services?

Google Cloud is widely recognized for its AI, ML,
and Kubernetes capabilities. It provides Vertex AI
for artificial intelligence and machine learning
and Google Kubernetes Engine (GKE) for managing
Kubernetes workloads.



## 4. What similarities did you observe among the three cloud providers?

The three cloud providers offer similar basic
infrastructure services. All of them provide
compute, storage, networking, and identity and
access management, although the names of their
services are different.
