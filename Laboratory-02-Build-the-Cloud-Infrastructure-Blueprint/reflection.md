Questions:

# 1.Which cloud infrastructure component do you think is the most important? Why?

# 2.How does Linux support cloud computing?

# 3.Why is technical documentation important before deploying infrastructure?

# 4.What new skills did you learn during this laboratory activity?

# 5.How has your GitHub portfolio improved after completing this mission?

During this laboratory activity, I learned more about cloud infrastructure and how its different components work together to support cloud computing. Among the components, I think **compute resources** are the most important because they provide the processing power needed to run applications, services, and commands. Without compute resources, the system would not be able to process tasks or provide services to users. However, compute, storage, networking, and the operating system must work together for a complete cloud environment.

I also learned how **Linux supports cloud computing**. Linux is commonly used in cloud environments because it is reliable, flexible, secure, and efficient. Through the KillerCoda terminal, I practiced using Linux commands to check the operating system, kernel version, CPU, memory, storage, hostname, and network information. This gave me a better understanding of how a cloud server can be monitored and managed using the command line.

Another important lesson from this activity is the importance of **technical documentation before deploying infrastructure**. Documentation helps organize important system information and provides a guide for setting up, managing, and troubleshooting infrastructure. It also makes it easier for other users or administrators to understand the system and avoid configuration mistakes.

During this laboratory, I learned new skills such as **using Linux commands, investigating system resources, identifying cloud infrastructure components, creating Markdown files, organizing documentation, and managing files in GitHub**. I also improved my ability to record technical information in a clear and organized way.

Lastly, my **GitHub portfolio improved** after completing this mission because I added more organized laboratory files, documentation, screenshots, and reflections. My repository now shows my progress and practical experience in cloud computing. Overall, this laboratory helped me connect the concepts I learned in class with actual hands-on experience using a Linux cloud environment.
