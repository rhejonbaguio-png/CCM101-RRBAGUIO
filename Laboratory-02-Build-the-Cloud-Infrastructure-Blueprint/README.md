# Laboratory 02 – Build the Cloud Infrastructure Blueprint

## Mission Overview

This laboratory activity focuses on understanding the basic
components of cloud infrastructure. I explored a Linux
environment using KillerCoda and identified the compute,
storage, networking, and operating system resources available.

I also researched the major cloud providers, including
Amazon Web Services (AWS), Microsoft Azure, and Google Cloud
Platform (GCP). I compared their equivalent cloud services
and created a simple cloud infrastructure diagram for a
fictional company.



## Objectives

The objectives of this laboratory activity are:

- To explore and investigate a Linux-based cloud environment.
- To identify the basic components of cloud infrastructure.
- To understand the purpose of compute, storage, and networking resources.
- To research and compare AWS, Microsoft Azure, and Google Cloud.
- To create a simple cloud infrastructure architecture diagram.
- To practice using Linux commands in a cloud environment.
- To document cloud computing activities using Markdown.

## Cloud Infrastructure Components

### 1. Compute Resources

The compute resources include the **CPU and RAM** of the
Linux environment. They provide the processing power and
memory needed to run applications, services, and commands.

### 2. Storage Resources

The storage resources include the **virtual disk and file
system**. They are used to store the operating system,
applications, files, and other data.

### 3. Networking Resources

The networking resources include the **network interface
and IP address**. They allow the Linux environment to
communicate with other systems and network services.

### 4. Operating System

The environment uses a **Linux-based operating system**.
The operating system manages the hardware and software
resources and provides the environment where commands and
applications can run.

## Linux Commands Executed

The following Linux commands were used during the laboratory:

| Command | Purpose |
|---|---|
| `lscpu` | Displays CPU and processor information |
| `free -h` | Displays RAM and memory information |
| `df -h` | Displays disk storage and file system information |
| `ip addr` | Displays network interfaces and IP addresses |
| `hostname` | Displays the hostname of the Linux environment |
| `uname -a` | Displays kernel and operating system information |
| `cat /etc/os-release` | Displays Linux distribution information |
| `ls` | Lists files and directories |
| `cd` | Changes the current directory |
| `mkdir` | Creates a new directory |
| `nano` | Creates and edits text or Markdown files |
| `cat` | Displays the contents of a file |
| `git add` | Adds files to the Git staging area |
| `git commit` | Saves changes to the Git repository |
| `git push` | Uploads changes to GitHub |
